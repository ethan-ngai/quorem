# 05 Schema mapping (#343)

The package maps PostgreSQL after product migrations 007–047 and auth migrations 001–004. No adoption SQL or Drizzle journal. Product and `quorem_auth` remain separate. The Node CLI preserves the product advisory lock `740010`, auth lock `(714901,1)`, separate ledgers, sorted filenames, unavailable-file and contiguous-prefix rejection, and a transaction per run. Use a direct operator connection:

```sh
DATABASE_URL=... vp -C packages/database run migrate product ../../apps/api/migrations
DATABASE_URL=... vp -C packages/database run migrate auth ../../apps/auth/migrations
```

Root workspace installation and lock integration belong to the orchestrator. The auth adapter export provides Better Auth table names, but its bigint passkey counter requires checked conversion at the plugin boundary; a complete assertion with this mapping remains unverified. Auth timestamps use Date mode; product timestamps preserve strings including PostgreSQL infinity. Bigints use JS bigint, numeric uses Drizzle's string representation, and bytea uses Buffer. JSON and public-boundary conversion remain the caller's responsibility.

## Validation

Executed 2026-10-30 with Node 24.21.0, Drizzle 0.45.4 and disposable PostgreSQL 17. Each history was applied as a prefix, upgraded and repeated; missing-prefix and unknown-file errors were rejected. Catalog columns, types, nullability, constraint names, foreign-key column order and index names/column order matched the mappings. A fresh rebuild matched the upgrade for catalog columns/defaults, constraint definitions, indexes, triggers and function definitions. Bigint maximum, high-precision numeric and binary bytes including NUL round-tripped through Drizzle. Typecheck passed. Test destroys schemas in the named disposable database:

```sh
docker run -d --rm --name quorem-hono-schema-spike -e POSTGRES_PASSWORD=fixture-only -e POSTGRES_DB=quorem_hono_schema_test -p 127.0.0.1:55432:5432 postgres:17
QUOREM_SCHEMA_TEST_DATABASE_URL='postgres://postgres:fixture-only@127.0.0.1:55432/quorem_hono_schema_test' vp -C packages/database run test
vp -C packages/database run typecheck
docker stop quorem-hono-schema-spike
```

This is a synthetic prefix upgrade, not a restored production-shaped database. Predicate/expression equivalence, check expressions, FK target/actions, defaults and upgrade data preservation are not exhaustively compared against the Drizzle model. No Worker query, concurrent migration, role-specific grant or production rollback proof is claimed. Kit introspection emitted malformed empty defaults, a truncated auth default, and reversed composite key order; corrected against PostgreSQL. SQL migrations remain authoritative. Kit 0.31.11 may author future diffs only after review against a database rebuilt from the same SQL sequence; normalize approved SQL into existing numbered history. Never run Kit push/migrate on shared databases. No migration 048 is included.
