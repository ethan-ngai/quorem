### Result backfill operator command

`make backfill-results` runs the shared audited operator lifecycle, normalizes legacy result headers/cases, then fills missing 059 status rows. Mutation requires explicit `--legacy-drained`; dry run rolls back one actual item. Interrupted commands report observed committed counts and mark the current outcome unknown for retry. Repeated bounded invocations report progress and refuse completion when a source is locked. Source rows are locked and checked against a SHA-256 digest before publication; malformed sources and conflicting rows fail closed.
