# 30a: Browser socket protocol core

`SocketSession` uses injected transport, verifier, current-authorization stamp, subscription, optional snapshot and command ports; no runtime provider or credential is retained. It subscribes before initial reads, coalesces notices, rechecks role stamps before private writes, repairs on heartbeat, rejects stale versions, bounds command lanes and output, and keeps ping/lease renewal independent of slow document commands. Interview RPC delegates pull/push/presence/peers/rule-event to existing domain ports; exact nested push JSON is preserved via the shared validated question JSON span scanner. Socket interview and submission notifications are bounded invalidations; full snapshots and results are HTTP-owned. Ordered document pulls are capped below the socket frame bound.
