# 31 Node sockets and fanout

`installNodeSockets(server, { origins, resolve, heartbeatMs })` installs a bounded WebSocket upgrade handler without mounting product routes. `resolve(request, signal)` supplies the shared 30 session ports and an optional lease-release callback. The shell checks exact origin, selects only the `quorem` subprotocol, verifies and authorizes before upgrade, and binds the verified identity for later rechecks. The shared session owns receipt credit, command serialization and authorization; its payloads and receipts pass unchanged. Send callbacks, a 256 KiB buffered limit, ping/pong, bounded setup, cancellation and lease cleanup protect transport lifetime. `grantSecurity` binds a copied verified managed, guest or invite grant using the shared identity owner; it retains no bearer or cookie bytes. Composition must build grants from verified credentials and supply current role/scope authorization, 25 lease acquire/renew/release and domain ports.

`MemoryFanout`, `PostgresFanout`, `CloudflareFanout` and `AppSyncFanout` implement server-only safe-notice publishing/subscription. `noticePublisher` sends match changes to both match and invite channels; a partial failure propagates so durable dispatch cannot acknowledge it. PostgreSQL LISTEN loss closes subscriptions and reconnects; clients repair through authoritative snapshots. Provider wire notices use the existing Go relay's uppercase fields and RFC3339 timestamps, with unknown fields discarded. Cloudflare sends its private bearer only to a validated relay endpoint; AppSync supports API key and SigV4 IAM via a caller-supplied credentials provider. Both reject redirects, bound responses and frames, and report failures without exposing credentials. AppSync protocol follows the [AWS Events WebSocket reference](https://docs.aws.amazon.com/appsync/latest/eventapi/event-api-websocket-protocol.html).
