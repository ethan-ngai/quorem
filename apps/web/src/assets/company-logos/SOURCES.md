# Company marks

File names match lowercase company names with spaces replaced by hyphens. The `.dark.svg` suffix supplies an optional dark-theme variant. Trademarks belong to their respective owners.

- Square site icons came from [Amazon](https://www.aboutamazon.com/), [Goldman Sachs](https://www.goldmansachs.com/), [Jane Street](https://www.janestreet.com/), [Optiver](https://www.optiver.com/), and [Samsung](https://www.samsung.com/us/).
- Uber uses the square icon published by Uber Technologies in its [App Store listing](https://apps.apple.com/us/app/uber-rides-eats-hotels/id368677368).
- The other marks come from [SVGL at d11faf1](https://github.com/pheralb/svgl/tree/d11faf16e695c805b87920c496a1746401e23e4b/static/library). See [SVGL-LICENSE.txt](SVGL-LICENSE.txt).
